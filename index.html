LearnDeck

Organize seus estudos como um Kanban: grupos, cards, timer, Pomodoro e anexos — tudo local, offline, direto no seu SQLite.

Electron 31 React 18 TypeScript 5 SQLite local Windows 10/11
Ver repositório Releases (instalador Windows)
LearnDeck é um aplicativo desktop — o React só acessa o SQLite através de IPC com o processo principal do Electron, então não existe (nem faz sentido ter) uma versão rodando direto no navegador. Esta página é só uma vitrine do projeto; para usar o app, baixe o instalador nas Releases ou rode a partir do código-fonte.

O que o LearnDeck faz

🗃️

Grupos hierárquicos

Organize matérias em árvore, tipo Faculdade → Cálculo → Integrais.

📋

Kanban customizável

Colunas dinâmicas por grupo, com drag-and-drop de cards.

⏱️

Timer & Pomodoro

Cronômetro por card e sessões Pomodoro configuráveis.

🔗

Relações entre cards

Pré-requisitos, bloqueios e cards relacionados.

📎

Anexos & subtarefas

Arquivos, prazos e checklist dentro de cada card.

📅

Calendário & notificações

Visão de agenda e alertas de itens atrasados.

📝

Notebook em Markdown

Editor visual de anotações por card.

📊

Dashboard

Estatísticas e gráficos de progresso de estudo.
